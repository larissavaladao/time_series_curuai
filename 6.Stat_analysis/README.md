# 6. Statistical Analysis and Visualization (Stat_analysis)

## Overview

This folder contains the workflow for consolidating environmental data and performing statistical analysis on the time series for the Curuá-Una region. Multiple approaches are explored to investigate the distributions, correlations, trends, and multivariate patterns of Total Suspended Solids (TSS) in relation to environmental forcing factors (precipitation, discharge, wind, land use, and land cover) at local and regional scales, also considering the seasonality of hydrological periods (Rising, High Water, Falling, and Low Water).

## Scripts and Notebooks

### 1. `1.joined_dataframe.ipynb`

Loads the pre-calculated CSVs from previous steps, adjusts calendar anomalies, applies interpolations for missing data, and generates the final unified DataFrames (`df_merged_local.csv` and `df_merged_regional.csv`).

### 2. `2.dist_correlation_tests.R` and `3.dist_correlation_tests_periods.R`

Performs normality tests (Shapiro-Wilk, Kolmogorov-Smirnov, Skewness), generates Q-Q/Density plots, and calculates the Kendall correlation matrix for the watersheds. The `_periods.R` script executes the same routine but segments the data by hydrological period (R, HW, F, LW).

### 3. `4.corr_plots.ipynb` and `5.corr_output.ipynb`

Consumes the results generated by the R scripts and builds correlation heatmaps, in addition to formatting and consolidating the summary tables for TSS.

### 4. `6.significance_time_series.R` and `7.significance_time_series_wp.R`

Executes hierarchical trend analyses on the time series. The `_wp.R` version performs the detection independently for each hydrological period.

### 5. `8.time_series_output.ipynb` and `9.time_series_output_wp.ipynb`

Maps the raw temporal data by plotting the linear trend line, trend classifications, and separating annual vs. hydrological data. The `_wp.ipynb` version generates independent multi-panel figures maintaining a fixed color scheme per period.

### 6. `10.pca_tests.R`

Uses the `FactoMineR` and `factoextra` packages to perform Principal Component Analysis (PCA) on the environmental data, generating variance statistics and biplots.

## Methodology

### Integration and Gap-filling

The data undergoes temporal and spatial standardization. Missing values in meteorological and hydrological time series are filled using polynomial and time-aware interpolation methods, resulting in "merged" (complete cases only) and "fillTSS" (interpolated data) scenarios.

### Hierarchical Trend Testing

The trend analysis uses a cascading strategy that stops at the first statistically significant trend found (p < 0.05), allowing an efficient classification of all evaluated variables into:

* **Linear Trend:** Monotonic linear patterns (Student's t-test).
* **Monotonic Trend:** Any monotonic direction that does not assume a linear relationship (Mann-Kendall).
* **Non-monotonic Trend:** Complex and structural oscillating patterns (WAVK Test).
* **No-Trend:** No significant trend detected.
